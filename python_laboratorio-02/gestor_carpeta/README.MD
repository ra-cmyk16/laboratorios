# Laboratorios de Python

Este repositorio contiene los ejercicios desarrollados durante los laboratorios de Python.

## Laboratorio 01: Cotizador de compra

**Descripción:** programa que calcula el valor de una compra teniendo en cuenta el precio, la cantidad, el descuento y los impuestos.

**Archivo principal:** `cotizador_compra.py`

**Ejecución:**

```bash
python cotizador_compra.py
```

## Laboratorio 02: Decisiones, ciclos y colecciones en Python

**Descripción:** programa que permite practicar estructuras condicionales, ciclos y colecciones en Python mediante un gestor de inventario.

**Archivo principal:** `gestor_inventario.py`

**Ejecución:**

```bash
python gestor_inventario.py
```

## Requisitos

- Tener Python instalado.
- Contar con los archivos correspondientes a cada laboratorio.
- Ejecutar los comandos desde la carpeta donde se encuentra el archivo correspondiente.

## Organización de los laboratorios

- **Laboratorio 01:** variables, entrada de datos y operaciones matemáticas mediante un cotizador de compra.
- **Laboratorio 02:** decisiones, ciclos y colecciones mediante un gestor de inventario.
