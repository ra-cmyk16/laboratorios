# Laboratorios de Python

Este repositorio contiene los ejercicios desarrollados durante los laboratorios de Python.

## Laboratorio 01: Cotizador de compra

**Descripción:** programa que calcula el valor de una compra teniendo en cuenta el precio, la cantidad, el descuento y los impuestos.

**Archivo principal:** `cotizador_compra.py`

**Ejecución:**

```bash
python cotizador_compra.py
```

## Laboratorio 02: Decisiones, ciclos y colecciones en Python

**Descripción:** programa de gestión de inventario que permite practicar estructuras condicionales, ciclos y colecciones en Python.

**Archivo principal:** `gestor_inventario.py`

**Ejecución:**

```bash
python gestor_inventario.py
```

## Laboratorio 03: Programación orientada a objetos

**Descripción:** desarrollo de un gestor de inventario utilizando clases, objetos, atributos, métodos y validaciones para administrar productos.

**Carpeta**
-`gestor_inventario`: almacena los archivos
**Archivos principales:**

- `main.py`: ejecuta el programa.
- `producto.py`: contiene la clase `Producto`.
- `inventario.py`: contiene la clase `Inventario`.

**Ejecución:**

```bash
python main.py
```

## Requisitos

- Tener Python instalado.
- Contar con los archivos correspondientes a cada laboratorio.
- Ejecutar los comandos desde la carpeta donde se encuentran los archivos de cada programa.
